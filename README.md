# Personal-Finance-Tracker
CIS-30A Python Personal Finance Tracker Project

## Project Description
The Personal Finance Tracker is a Python program that helps users manage their personal finances by tracking income, expenses, and budgets.

## Features
- Create a monthly budget
- Add income
- Add expenses
- View financial summaries
- Save financial information to a text file
- Check if the user is within their budget

## Technologies Used
- Python
- Custom Python Module
- Object-Oriented Programming
- File Handling
- Exception Handling

## Files
- FinalProjectCIS-30A.py - Main program file
- finance_tools.py - Custom module used for calculations
- Summary and Pseudocode.pdf - Project Documentation and Pseudocode
- summary.txt - text file that is opened by the program

## How to Run
1. Download both Python files.
2. Make sure `finance_tools.py` is in the same folder as the main program.
3. Run `FinalProjectCIS-30A.py`.
